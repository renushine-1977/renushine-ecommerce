# Renu Shine website

Static storefront for Renu Shine vehicle care products. The site is built in `index.html` and can be hosted with GitHub Pages. Product photos came from the supplied business images and sit alongside the main page.

## Publish with GitHub Pages

1. Create a GitHub repository named `renu-shine` and add these site files.
2. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source.
3. Push changes to the `main` branch. The included Pages workflow will publish the site.
4. GitHub Pages will show the published `github.io` address in the Pages settings.
5. For a custom domain, register a domain with a registrar, add it in Pages settings, and configure the DNS records requested by GitHub.

The site currently accepts product enquiries through WhatsApp. Online payment and order fulfilment need to be connected separately before customers can pay on the website.
