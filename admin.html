Publish a change

  1. Sign in to GitHub when asked.
  2. Edit the product page or upload the photo, then choose Commit changes.
  3. GitHub Pages publishes the commit to the customer store automatically, usually after a short wait.

This free admin page uses GitHub’s account sign-in for permission to save edits. GitHub Pages is a static host, so it does not provide a separate private admin login or a live inventory database.
